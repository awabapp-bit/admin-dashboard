# منصة أواب الإلكترونية — لوحة تحكم المسؤول

موقع مستقل بالكامل عن موقع المستخدم. يشتركان فقط في نفس مشروع Firebase.

| الملف | الوظيفة |
|---|---|
| `index.html` | دخول المسؤول (نقطة الدخول) — admin / 123 |
| `home.html` | كل الكورسات والمسابقات + إحصائيات |
| `add-competition.html` | إضافة كورس أو مسابقة جديد(ة) |
| `competition.html?id=...` | إدارة محاضرات عنصر محتوى معيّن |
| `lesson.html` | محاضرة: فيديوهات متعددة + اختبارات متعددة + مرفقات (روابط PDF/صور) |
| `users.html` | كل الحسابات (بما فيها حسابات المسؤولين) — بحث/عرض/إعادة تعيين/حظر |
| `user-detail.html` | تفاصيل حساب + إرسال رابط استرجاع كلمة مرور |
| `participants.html` | مشتركو (المشتركين فعليًا) عنصر محتوى معيّن ونقاطهم |

## الملفات المطلوبة بجانب الصفحات (كل حاجة في نفس المستوى)
```
awab-admin-site/
├── logo.png
├── style.css
├── firebase-config.js
├── icons.js
├── admin-shell.js
└── *.html
```

## ⚠️ قبل الاستخدام
1. Firebase Console ← Authentication ← Settings ← Authorized domains ← أضف نطاق نشر هذا الموقع.
2. Firebase Console ← Realtime Database ← Rules ← الصق محتوى `firebase-rules.json` المرفق.

لا حاجة لتفعيل Firebase Storage: المرفقات أصبحت روابط خارجية يلصقها المسؤول يدويًا، مش رفع فعلي، فملف `storage-rules.txt` المرفق أصبح غير مطلوب.

## دخول المسؤول

من `index.html`:
- **اسم المستخدم:** `admin`
- **كلمة المرور:** `123`

خلف الكواليس، هذه البيانات بتسجّل دخولك تلقائيًا لحساب Firebase حقيقي: `admin@awab.su.com` بكلمة مرور `500500`. يُنشأ تلقائيًا أول مرة تسجّل دخول. الجلسة محفوظة تلقائيًا بعد أول دخول.

**فايدة إن الحساب الحقيقي معروف**: نفس الحساب تقدر تدخل بيه مباشرة في **موقع المستخدم** (مش هنا) عشان تتصفح كأي مستخدم عادي وترد على تعليقات الناس على الفيديوهات.

## كورسات ومسابقات معًا
عند إضافة محتوى جديد (`add-competition.html`)، تختار نوعه: **كورس** أو **مسابقة**. الفرق شكلي بس (تسمية الزرار والأيقونة عند المستخدم)، البنية التقنية واحدة (محاضرات فيها فيديوهات/اختبارات/مرفقات).

## الاشتراك الحقيقي
المستخدم بيشترك فعليًا (مش مجرد تصفح) من زر "اشتراك/انضمام" في صفحة تفاصيل المحتوى عنده، بعد تأكيد صريح منه. صفحة `participants.html` هنا بتعرض المشتركين الفعليين بناءً على ده (عقدة `enrollments/{compId}`)، حتى لو لسه ما بدأش أي محاضرة أو ما جمعش نقاط.

## إشعارات تلقائية للمستخدمين
- عند إضافة محاضرة جديدة لكورس أو مسابقة (من `lesson.html`): إشعار تلقائي **للمشتركين الفعليين في هذا المحتوى فقط** (مش كل المستخدمين).
- عند رد المسؤول على تعليق (من موقع المستخدم): إشعار لصاحب التعليق تلقائيًا.
- **مفيش** إشعار عام لكل المستخدمين عند إضافة كورس/مسابقة جديد بالكامل.

## المرفقات (روابط PDF وصور)
في `lesson.html`، قسم "المرفقات" بقى بيسمح بإضافة رابط خارجي جاهز (اسم + رابط + نوع PDF/صورة) لكل محاضرة، بدل رفع ملف فعلي. المسؤول لازم يرفع الملف بنفسه على أي خدمة استضافة (Google Drive، Dropbox، إلخ) ثم يلصق رابطه هنا. يظهر تلقائيًا في قائمة محتوى المحاضرة عند المستخدم. **لا يتطلب Firebase Storage** إطلاقًا.

## صفحة الحسابات
`users.html` بطاقات (مش جدول)، بتعرض **كل** الحسابات (بما فيها حسابات المسؤولين، بشارة "مسؤول" مميزة)، مع بحث وفرز (الأحدث / الأعلى نقاطًا / أبجديًا / المحظورين أولاً). أزرار تصفير النقاط والحظر مخفية تلقائيًا لحسابات المسؤولين (حماية من الحظر بالخطأ).

## ملاحظة مهمة عن إرسال رابط إعادة تعيين كلمة المرور
زر "إرسال رابط إعادة تعيين كلمة المرور" في `user-detail.html` **يرسل إيميل حقيقي فعليًا** عبر Firebase، ويوجّه المستخدم لموقع `awab-reset-site` المستقل بدل صفحة Firebase العامة.

## مهم: روابط المواقع التانية
زر "عرض الموقع"، وزر "العودة لموقع المنصة"، وزر إرسال رابط إعادة التعيين، كلهم بيشاوروا على مواقع مستقلة. الروابط الحالية:
```
موقع المستخدم: https://awabapp-bit.github.io/awab-user-site/
موقع إعادة تعيين كلمة المرور: https://awabapp-bit.github.io/awab-reset-site/
```
لو الروابط الفعلية بعد النشر مختلفة، حدّثهم في:
- `admin-shell.js` → `const USER_SITE_URL` و `const RESET_SITE_URL`
- `index.html` → رابط "العودة لموقع المنصة" أسفل الفورم

## ⚠️ ملاحظة عن ملف storage-rules.txt
لم تعد لوحة التحكم تستخدم Firebase Storage؛ الملف مُبقًى فقط كمرجع سابق ولا حاجة للصقه في Firebase Console.
